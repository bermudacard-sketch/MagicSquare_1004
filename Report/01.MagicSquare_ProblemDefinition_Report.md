# MagicSquare_1004 — 문제 정의 리포트

**문서:** `01.MagicSquare_ProblemDefinition_Report.md`  
**작성 기준:** Mom Test 인터뷰 + 세션 3 워크북 초안  
**도메인:** 4×4 마방진, 빈칸 2개(0), 1~16, 목표 합 34

---

## 1. Mom Test 결과

| 항목 | 내용 |
|------|------|
| **페르소나** | 4×4 격자에서 빈칸 2개(0)를 1~16으로 채워 합 34를 맞추는 학습자. 손계산·코드·슬라이드(자료 제작)를 오가며 다룸. |
| **진짜 문제 (한 문장)** | 빈칸을 채운 뒤 “완성”이라고 믿을 때, 행·열·대각선 합을 **빠짐없이** 확인하지 못해 틀린 채로 시간을 쓴다. |
| **Mom Test 증거 3줄** | ① 지난주 빈칸 2개를 넣고 행·열·대각선 합을 맞췄다고 생각했으나 **대각선 하나를 빼먹어 20분을 낭비**했다. ② 그 20분 동안 풀이만 한 게 아니라 **ECB 프로젝트 소개 슬라이드 같은 학습 자료**를 만들고 있었다. ③ “맞췄다”는 판단은 했지만, **10개 줄(행 4 + 열 4 + 대각선 2) 전체를 일관되게 검증하지 않은** 것이 실패 원인이었다. |

---

## 2. 인터뷰 요약

### 진행한 질문

1. 마지막으로 4×4 부분 마방진(일부 칸만 채워진 상태)을 손으로나 코드로 다루려고 했을 때, 그게 어떤 상황이었어?
2. 그 20분 동안에 실제로 뭘 하고 있었어?
3. 그 자료를 만들면서, 대각선 하나를 빼먹었다는 걸 어떻게 알게 됐어? *(미답변 — 증거 보강 필요)*

### 핵심 답변

- **시점:** 지난주
- **작업:** 빈칸 2개를 채우고 행·열·대각선 합을 맞춤
- **실수:** 대각선 하나 검증 누락
- **비용:** 20분 낭비
- **맥락:** 4×4 마방진 ECB 프로젝트 소개 자료(빈칸 2개 예시 격자) 제작 중

## 3. 표면 문제 vs 진짜 문제

| 구분 | 내용 |
|------|------|
| **표면 문제** | “빈칸 2개를 채워 4×4 마방진을 **풀어라**” |
| **진짜 문제** | 풀이 후 **검증 누락**으로 “완성”을 잘못 판단하고 시간을 낭비함 |
| **이번 세션에서 다루지 않음** | 빈칸 위치 찾기, 자동 풀이(Solver), ECB 슬라이드/GridUI, 입력 폼, 결과 화면 |

## 4. 세션 3 워크북

### 4.1 주제 (한 문장)

> 4×4 부분 마방진 후보 격자가 “합 34로 완성됐는지”를, 행·열·대각선 10줄을 빠짐없이 검증하는 규칙과 확인 루프를 만든다.

### 4.2 R-G-I-O

| | |
|---|---|
| **Role** | 4×4 부분 마방진 학습자 — 빈칸 2개(0), 나머지 1~16, 목표 합 34 |
| **Goal** | 후보 격자를 “완성”이라고 말하기 **전에**, 10개 줄 합이 모두 34인지 **재현 가능하게** 확인한다 |
| **Input** | 4×4 정수 격자 (0 = 빈칸, 그 외 1~16) |
| **Output** | 줄별 합 목록(행 4 + 열 4 + 대각선 2) + **유효 / 무효** 판정 |

### 4.3 성공 기준 3개 (Mom Test 증거 연결)

| # | 성공 기준 | Mom Test 연결 |
|---|-----------|----------------|
| 1 | **10줄 전부** 검사한다 — 행 4, 열 4, 대각선 2를 누락 없이 출력한다 | 증거 ①·③: 대각선 하나를 빼먹어 20분 낭비 → “빠진 줄”이 없어야 함 |
| 2 | 대각선 하나만 틀린 **실패 격자**에 대해 `무효`를 반환하는 테스트가 있다 | 증거 ①: 지난주 실수 패턴을 테스트로 고정 → 같은 실수 재발 방지 |
| 3 | 올바른 완성 격자(README 예시 등)에 대해 10줄 합이 모두 34이고 `유효`를 반환한다 | 증거 ②: 자료 제작 중에도 **같은 기준**으로 빠르게 확인 가능 |

### 4.4 8계층 — 세션 3 범위

| 계층 | 세션 3 | 산출물 (예시) |
|------|--------|---------------|
| **Rule** | ✅ | 합 34 = 행 4 + 열 4 + 대각선 2 (10줄). 완성 격자는 1~16 각 1회, 0 없음. |
| **Command** | ✅ | `validate` — 격자를 받아 줄별 합 + 유효/무효 출력 |
| **(Skill)** | △ 선택 | Rule+Command를 한 번에 호출하는 래퍼 |
| **Test Loop** | ✅ | 완성 격자 → `유효`; 대각선 하나만 틀린 격자 → `무효` |
| Entity | ❌ | `MagicSquare`, `Cell` (세션 4+) |
| Control | ❌ | `MissingFinder`, `Solver` (세션 4+) |
| Boundary | ❌ | `GridUI`, `InputHandler` (세션 4+) |
